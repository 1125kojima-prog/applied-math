# 応用数学（線形代数）インタラクティブ学習

## 概要

線形代数（部分空間・1次独立・ランク・基底・次元）を、操作しながら理解するためのWebアプリです。
講義ノートの第1回〜第7回に対応する12個のシミュレーションを収録しており、ベクトルをドラッグしたり数値を入力したりすると、判定結果や計算過程（簡約化のステップなど）がその場で更新されます。各シミュレーションには確認問題と用語集も付いています。

## 使い方

1. 画面左（スマホでは上部）のナビゲーションから、学びたい回（第1回〜第7回）を選びます。
2. 各ページの冒頭に、対応する講義資料のファイル名とノートのページ番号が表示されます。
3. 「操作」欄で数値を入力するか、図（Canvas）の点を直接ドラッグして動かします。1次独立の判定（第3・4回）はR²・R³を切り替えて、2次元はドラッグ、3次元は視点をドラッグで回転させながら確認できます。
4. 「表示」欄に判定（○/×）と理由、計算のステップが連動して表示されます。
5. 「確認問題」で理解度をチェックし、「用語の確認」で関連用語を復習します。

## 使用した技術スタック

- TypeScript（strict）
- フレームワーク不使用のDOM操作（Vanilla）
- Canvas 2D API（devicePixelRatioに対応した高解像度描画）
- [KaTeX](https://katex.org/)（CDN読み込み、数式表示）
- Node.js 標準のテストランナー（`npm test`）
- GitHub Pages（静的ホスティング）

## ローカルで動かす

Node.js 18以上が必要です。

```bash
git clone https://github.com/1125kojima-prog/applied-math.git
cd applied-math
npm install
npm run build
npx http-server -c-1
```

表示されたURL（例: http://127.0.0.1:8080/ ）をブラウザで開いてください。
`index.html` はES Modulesを使用しているため、`file://` で直接開くとブラウザのCORS制限で動作しません。簡易サーバー経由で開いてください。

## ビルド・テスト

```bash
npm run build   # TypeScript を js/ にコンパイル
npm test        # ビルド後、Node.js標準テストランナーでユニットテストを実行
```
